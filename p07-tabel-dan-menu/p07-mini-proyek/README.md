# PustakaKu – Sistem Katalog Buku Dongeng

## Deskripsi
PustakaKu merupakan aplikasi desktop sederhana berbasis Java Swing yang digunakan untuk mengelola katalog buku dongeng. Aplikasi ini dibuat sebagai bagian dari Mini Proyek Praktikum Pemrograman Berorientasi Objek (PBO).

Aplikasi menyediakan fitur pengelolaan data buku, mulai dari menambahkan, mengubah, menghapus, hingga mencari data berdasarkan kode, judul, dan penulis.

## Fitur Aplikasi
- Menampilkan daftar buku dongeng.
- Menambahkan data buku.
- Mengubah data buku.
- Menghapus data buku dengan konfirmasi.
- Mencari buku berdasarkan kode, judul, dan penulis.
- Mengurutkan data melalui kolom tabel.
- Menampilkan jumlah keseluruhan buku dan jumlah buku yang tersedia.
- Validasi input kode, judul, dan tahun terbit.
- Mengelola status buku, yaitu tersedia dan dipinjam.

## Data Awal
Aplikasi dilengkapi dengan lima data awal berupa cerita dongeng:

1. Kancil dan Buaya
2. Timun Mas
3. Bawang Merah dan Bawang Putih
4. Malin Kundang
5. Keong Mas

## Teknologi yang Digunakan
- Java
- Java Swing

## Deklarasi Penggunaan Artificial Intelligence (AI)

Dalam proses pengerjaan mini proyek ini, saya menggunakan bantuan **Google Gemini** sebagai alat pendukung pengembangan aplikasi.

Penggunaan AI dimanfaatkan untuk:
- Membantu memahami konsep pemrograman Java Swing.
- Memberikan referensi dan arahan dalam penyusunan kode program.
- Membantu mengidentifikasi serta memperbaiki kesalahan (debugging).
- Memberikan saran dalam pengembangan fitur dan struktur aplikasi.

Seluruh hasil bantuan AI ditinjau dan disesuaikan kembali dengan kebutuhan proyek. Penggunaan AI dilakukan sebagai sarana pendukung pembelajaran, bukan sebagai pengganti pemahaman terhadap materi yang dipelajari.

## Penutup
PustakaKu diharapkan dapat menjadi contoh penerapan konsep Pemrograman Berorientasi Objek dalam pengembangan aplikasi desktop sederhana, khususnya pada pengelolaan data menggunakan Java Swing.
